# mac_wallpaper_grabber

Скачивает всё, что видно в Настройках macOS → **Wallpaper**, в выбранную
папку. Секции — те же, что в Настройках:

- **Dynamic Wallpapers** — динамические обои (меняются от времени суток)
- **Landscape**, **Cityscape**, **Underwater**, **Earth** — видео-обои Aerial
- **Mac** — встроенные обои текущей версии macOS
- **Pictures** — статичные картинки

Обои, которые система уже скачала, копируются с диска. Остальные
скачиваются напрямую с серверов Apple — включая те, что вы ещё ни разу
не нажимали в Настройках (видео по манифесту `entries.json`, картинки по
официальному каталогу `mesu.apple.com`). Скачанное раскладывается по
папкам с названиями секций.

## Запуск

```bash
python3 mac_wallpaper_grabber.py
```

Скрипт покажет секции с количеством найденного, спросит какие взять
(целиком или по одному), предложит папку (Загрузки / Рабочий стол /
Картинки / выбор в Finder) и скачает.

Без вопросов — всё сразу:

```bash
python3 mac_wallpaper_grabber.py --all --dest ~/Pictures/wallpapers
```

Полезные флаги:

| Флаг | Что делает |
|---|---|
| `--sections Landscape,Earth` | только указанные секции |
| `--video hdr` | видео в 4K HDR (по умолчанию 4K SDR 240fps) |
| `--local-only` | без сети, только то, что уже на диске |
| `--workers N` | параллельных загрузок (по умолчанию 3) |

## Надёжность

- докачка после обрыва соединения (HTTP Range + `.part`)
- 3 попытки на каждый файл
- уже скачанные файлы пропускаются — можно запускать повторно
- параллельные загрузки с общим прогрессом

Поддерживается macOS Sonoma 14, Sequoia 15 и Tahoe 26.
Нужен только Python 3 — сторонние библиотеки не требуются.
