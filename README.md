# mac_wallpaper_grabber

Простой скрипт для скачивания обоев macOS — как в Настройках:
выбираете видео-обои (Aerial) или обычные обои, отмечаете нужные
и указываете папку, куда их сохранить.

## Запуск

```bash
python3 mac_wallpaper_grabber.py
```

Скрипт задаст три вопроса:

1. **Что скачать?** — видео-обои (Aerial) или обычные обои
2. **Какие?** — список найденного с номерами (Enter — взять все)
3. **Куда?** — Загрузки / Рабочий стол / Картинки или своя папка через Finder

Видео, которые система уже скачала, копируются с диска; остальные
скачиваются с серверов Apple. Уже сохранённые файлы пропускаются.

Поддерживается macOS Sonoma 14, Sequoia 15 и Tahoe 26.
Нужен только Python 3 — сторонние библиотеки не требуются.
